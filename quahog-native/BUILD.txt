QUAHOG 0.6.0 - C11 SOURCE BUILD

Players: the Mac and Windows libraries are already compiled. Copy the mod
folder into the launcher's Mods folder. No compiler or Python is needed.

MAC REBUILD
On a Mac with Apple's Command Line Tools installed, run from this folder:
sh BUILD_MAC.sh

This builds and ad-hoc signs both bin/macos-arm64/quahog_native.dylib and
bin/macos-x86_64/quahog_native.dylib. It uses C11 and the system C runtime.
Targets: arm64 macOS 11.0+, x86_64 macOS 10.15+ (game requirements may be newer).
No Objective-C, C++, Python, third-party runtime, or game rebuild is required.

WINDOWS REBUILD
With Zig 0.13.0 on PATH, run BUILD_WINDOWS.cmd, or from this folder:
zig cc -target x86_64-windows-gnu -std=c11 -O2 -Wall -Wextra -Werror -shared -Isdk src/quahog_native.c src/qcore.c src/qformats.c src/qhost.c src/qmacho.c src/qmac.c -luser32 -o bin/windows-x86_64/quahog_native.dll

TESTS
On Linux or Mac, with a C compiler, run from this folder:
sh tests/run_checks.sh

On a Mac, also exercise the actual compiled library through dyld:
sh tests/run_macos_dylib.sh

The Mac loader check uses synthetic game files and mock API 1.3, 1.4 and 1.5
hosts. It checks both normal exports and hidden host symbols (Mach-O fallback),
loads and unloads the actual dylib, verifies retained buffer reuse, and checks
portal drawing, travel, pause, saved placement, rescue and override rollback.
This is not a real game/ISO playtest.

The fixtures are authored synthetic scenes, archives, PE and Mach-O metadata,
not extracted retail game data. Tests require the included real mod assets.
The assembler reference hash was independently produced by the previous Python
assembler during development. No Python code is required by these tests.

Optional parser memory/bounds checks (GCC or Clang on a supported host):
cc -std=c11 -O1 -g -UNDEBUG -fsanitize=address,undefined -fno-omit-frame-pointer -Isrc tests/test_macho.c src/qcore.c src/qmacho.c -o /tmp/quahog-macho-asan
/tmp/quahog-macho-asan

SOURCE MAP
quahog_native.c  API callbacks, travel, placement persistence and diagnostics.
qportal.h        Native projected portal drawing.
qformats.c      Scene/RARC/Yaz0 parsing, stage selection, asset verification,
                archive assembly and collision-derived portal placement.
qhost.c         Windows symbols, native VFS, memory settings, retained buffers,
                archive cache and override restoration.
qmacho.c        Bounded Mach-O and universal executable symbol parser.
qmac.c          macOS dyld lookup, ASLR/UUID checks and archive-registry lifetime.
qcore.c/.h      Allocation, hashes, file IO and read-only executable mappings.
asset_hashes.h  Pinned map asset sizes and SHA-256 checksums.

The Mac mod does not use raw 32-bit game pointers. The host VFS and native mod
API carry host-sized pointers, including on the Apple Silicon game port.
When changing assets, update asset_hashes.h and assets/assets.json, and bump
the assembler/cache version. Close the game before installing a rebuilt mod.
