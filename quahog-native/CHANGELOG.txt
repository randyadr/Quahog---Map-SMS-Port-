0.5.1 - Large executable compatibility
- Fixed "Invalid file size" when reading a large Skin Selector game EXE.
- Use read-only mapped executable metadata with GetFileSizeEx on Windows,
  instead of the bounded asset reader and its 256 MB limit.
- Executable mapping resources are closed on success and on load failure.
- Added sparse 300 MiB and 3 GiB executable tests, including symbol tables
  beyond 2 GiB, normal/corrupt files, arena transfer and error cleanup.
- Remains entirely native C with no Python or installer dependency.

0.5.0 - Native C
- Replaced every Python preparation/archive/placement step with native C11.
- Converted the C++ DLL implementation to C11 as well.
- Removed interpreter discovery, automatic Python installation, networking,
  process launch, Python scripts and unused C++ runtime libraries.
- Read the active stage through the game's existing native VFS.
- Preserved the Quahog assets, visible portals, controls, saved placements,
  return-episode behavior, collision, fall rescue and memory-setting handling.
- Added atomic native cache publication and damaged-cache rebuilding.
- Kept all preparation at startup, with no normal gameplay filesystem polling.
- Kept complete C source and authored offline tests beside the compiled DLL.
- This release rebuilds prepared maps once into prepared-c-v5; old caches are
  not imported. Existing custom portal positions continue to work.
