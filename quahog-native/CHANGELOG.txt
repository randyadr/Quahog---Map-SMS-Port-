Quahog 0.4.4 - Standalone release
- Removed unused alternate-map code, preparation paths and documentation.
- Quahog-only portal preview, tests and rebuilt native DLL.
- Retains automatic Python setup, map assets, travel keys and portal placement.

Quahog 0.4.3 - Automatic Python setup
- Reuses installed compatible x64 Python; installs automatically when none is detected.
- Downloads the official Python 3.14.10 installer from python.org over HTTPS.
- Requires the pinned official SHA-256 and Windows signature checks to pass.
- Visible per-user installation with no setup choices or Enter key required.
- Continues map preparation after installation without restarting the game.
- Serializes concurrent Quahog installs and rechecks after acquiring the lock.
- Handles cancellation, offline failure, corrupt downloads and installer errors.
- Checks Windows version resources to skip unsupported automatic candidates.
- No Python EXEs, runtime files or installer are bundled in the ZIP.
- Existing memory-setting behavior, maps, portals and travel are retained.

Quahog 0.4.2 - Installed Python edition
- Separate distribution requiring installed 64-bit Python 3.10 or newer.
- Removed the entire embedded runtime: no EXE, PYD or Python runtime DLL files.
- Detects registered installed Python first, then real interpreter files on PATH.
- Optional one-line python-path.txt selects a custom external interpreter.
- Rejects missing, empty-alias, x86 and mod-local executables before launch.
- Validates the actual Python version/bitness and logs the interpreter path.
- Retains visible preparation and the v0.4.1 manual memory-setting restart.
- Map assets, portal rendering, portal placement and game travel are unchanged.
- No Python download/install, pip, new installer, launcher EXE or patcher.
- Full ZIP only: remove the old runtime folder when updating an existing copy.

Quahog 0.4.1 - Startup cleanup
- Removed automatic game self-relaunch and window hiding.
- Removed suspended child creation, thread resumption, process jobs and forced
  process termination from the mod's startup code.
- Preparation runs in a normal visible console without inherited handles.
- Console output and failures still go to automatic-setup.log/startup.log.
- Low memory uses the game's normal settings file, backed up before updating
  SMS_MEM_MB only. Close the game and press Play again once after the prompt.
- Existing map caches, assets, portal settings, travel and hotkeys retained.
- Official bundled runtime unchanged; custom DLL remains unsigned.
- Defender result unknown. No antivirus exclusions or bypasses added.

Quahog 0.4.0
