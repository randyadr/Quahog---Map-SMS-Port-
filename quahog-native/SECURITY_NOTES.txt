QUAHOG 0.4.4 - AUTOMATIC PYTHON SETUP
Author: Randyadr

No Python runtime, EXE files, PYD modules or installer is included in the ZIP.
The only shipped PE binary is the unsigned native quahog_native.dll. Source
and offline tests are included. The mod needs an external x64 Python 3.10+.

Automatic setup is enabled in this edition. A compatible registered/PATH
Python is reused. Otherwise the mod downloads the official Python 3.14.10
Windows x64 installer over normal certificate-checked HTTPS from:
https://www.python.org/ftp/python/3.14.10/python-3.14.10-amd64.exe
The release page's SHA-256 is pinned in the compiled mod:
92480239264744fe0386a1bd8275786fefa126e3129e56a68e22b52c73329965

The downloader rejects redirects, HTTP failures and downloads over 64 MiB.
It writes to a fresh random temporary directory. Before execution, SHA-256
must match AND Windows Authenticode verification must succeed, with chain
revocation checking enabled. A read handle prevents file replacement or
rewriting between verification and completion of installation. There is no
fallback that runs unverified bytes or disables certificate checks. The
downloaded file is removed after use. It is never copied into the mod folder.

The official installer runs via normal CreateProcessW with /passive progress,
/norestart and InstallAllUsers=0. It is given no inherited handles. It installs
for the current user, without a launcher, PATH/file-association changes,
shortcuts or pip. The installer creates Python's normal user registration
and uninstall entries. The mod itself only reads the Python registry keys.
It does not use PowerShell, shell commands, execution-policy bypasses, or
request elevation. Windows organizational policies may still block setup.

A named local mutex prevents overlapping Quahog installer launches. The mod
rechecks discovery after waiting. Network/verification errors do not invoke
the installer. Cancellation or failed installation does not proceed to map
preparation. Windows restart requests never cause an automatic restart.
No forced process termination, hidden game relaunch, suspended process,
security-setting changes, AV exclusions, packers or obfuscation are added.

The game uses its normal native mod/disc APIs. Map archives are assembled
in the mod cache and the source disc is read-only. The existing one-time
SMS_MEM_MB adjustment is preserved with a backup and manual game restart.
Python installation is separate from that memory-settings step.

The official installer was downloaded here and its checksum verified. The
Windows DLL compiled with warnings as errors, and offline tests passed.
Windows Authenticode/install execution and Defender were not tested here;
this is not a guarantee that antivirus products will accept the mod.
See VALIDATION.json, binary.json and PACKAGE_MANIFEST.json for results/hashes.
